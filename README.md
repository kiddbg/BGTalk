# BGTalk iOS

BGTalk is an iPhone real-time conversation translation app focused on Bulgarian, English, and Spanish.

## Current foundation

- SwiftUI app entry point
- Native conversation screen
- Bulgarian, English, and Spanish language selection
- Microphone/listening interaction placeholder
- Transcript area ready for speech recognition

## Next implementation stages

1. Add speech recognition and microphone permissions.
2. Add translation service abstraction and real-time translation pipeline.
3. Add speech synthesis for translated responses.
4. Add two-person conversation mode.
5. Add transcript/history and settings.
6. Add testing and production configuration.
